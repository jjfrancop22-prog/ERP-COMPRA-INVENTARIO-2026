ERP COMPRAS V4 — C14.1 PRODUCCIÓN GITHUB + NETLIFY
=====================================================

ARQUITECTURA FINAL
GitHub  -> almacena el código
Netlify -> publica la PWA
Firebase Authentication -> usuarios/login
Cloud Firestore -> datos y sincronización Multi-PC

NO SE USA FIREBASE HOSTING.

ANTES DE PUBLICAR
1. Confirmar que C14.0-R2 funciona en localhost:8080.
2. Confirmar Outbox = 0.
3. Descargar respaldo integral desde Administración ERP.
4. NO cambiar Firestore Rules.

SUBIR A GITHUB
1. Crear un repositorio privado o público en GitHub.
2. Subir TODO el contenido de esta carpeta (no la carpeta contenedora externa).
3. Deben quedar en la raíz:
   index.html
   service-worker.js
   manifest.webmanifest
   assets/
   icons/
   netlify.toml

CONECTAR NETLIFY
1. Netlify -> Add new project / Import an existing project.
2. Elegir GitHub.
3. Seleccionar el repositorio del ERP.
4. Build command: dejar vacío.
5. Publish directory: .
6. Deploy.

FIREBASE AUTHENTICATION
Después de que Netlify entregue la URL, por ejemplo:
https://erp-compras-psi.netlify.app

Ir a:
Firebase Console -> Authentication -> Configuración -> Dominios autorizados

Agregar SOLO el dominio:
erp-compras-psi.netlify.app

No escribir https:// ni rutas.

VALIDACIÓN FINAL
1. Abrir la URL Netlify.
2. Confirmar BUILD C14.1.
3. Iniciar sesión Administrador.
4. Confirmar Firebase sin error.
5. Confirmar Outbox = 0.
6. Abrir la misma URL en otra computadora.
7. Probar edición PC A -> PC B y PC B -> PC A.
8. Probar cambio de usuario y roles.
9. Instalar PWA desde la URL Netlify.

ACTUALIZACIONES FUTURAS
Actualizar archivos en el mismo repositorio GitHub.
Netlify vuelve a publicar automáticamente.
No ejecutar firebase deploy.
No modificar Firestore Rules para una actualización normal.
